What we made

Six phases, all visible

Your program goes from characters to tokens, a parse tree, a checked tree, three-address code, shorter code and finally machine code for a small Turtle VM, which draws the picture.

It runs in your browser

Every keystroke runs the whole compiler again, from the first token to the last instruction. Nothing is sent to a server: the page is the compiler.

And on the command line

turtlec runs the same compiler in a terminal. It prints what any phase made, saves the drawing as SVG and the machine code as a .tvm file it can run again.

$ turtlec star.turtle
$ turtlec star.turtle --phase opt
$ turtlec star.turtle --svg star.svg

How it was built

One compiler, one design system

compiler.js, shared by the site and the CLI

All six phases live in one plain JavaScript file with no page code in it. The website and turtlec both load that file, so a rule fixed once is fixed everywhere. The grammar, the limits, the colours and the opcodes are tables in it, and every page reads them from there.

A design system first

We drew the pages before we built them: one paper palette, a hue for each phase, and three typefaces. The website is generated from those design files and checked against them pixel for pixel.
